# 桥联

电脑和安卓、鸿蒙 7 手机连同一个 Wi-Fi 后，用电脑收发文件、看手机画面，并做远程操作。

电脑程序是一个 Windows 可执行文件。它只在本机打开页面 `http://127.0.0.1:8787`，再主动连到手机。手机上会显示 6 位配对码，配对成功后电脑会记住这台手机，下次不用再输，除非在手机上点「取消所有配对」。

## 电脑

需要安装 [Go](https://go.dev/dl/) 1.22 或更新版本。在 `qiaolian` 目录执行：

```powershell
.\scripts\build-windows.ps1
.\dist\qiaolian.exe
```

macOS 或 Linux 上交叉编译：

```sh
sh scripts/build-windows.sh
```

没有 Go 的 Windows 电脑，也可以在已安装 Go 的机器上编出 `dist/qiaolian.exe`，把这一个文件拷过去直接运行。程序会打开浏览器。没自动打开时，手动访问 `http://127.0.0.1:8787`。

第一次运行如果 Windows 防火墙询问，允许专用网络，这样电脑才能收到手机的发现广播。发现不到手机时，在左边填手机页面上显示的 IP，端口保持 `37622`。

## 安卓

用 Android Studio 打开 `android` 目录，装到手机上。打开桥联后：

1. 点「允许访问全部文件」，否则只能看到应用自己的目录。
2. 要投屏时点「允许投屏」，并在系统弹窗里同意。
3. 要远程点击、滑动、输入文字时点「打开远程控制」，在无障碍里启用桥联。

然后在电脑上连接，输入手机上的配对码。

安卓可以：

- 浏览、上传、下载、新建、删除、重命名内部存储里的文件
- 投整个屏幕
- 远程点击、滑动、滚动
- 返回、主页、最近任务
- 把文字送进当前输入框
- 读写剪贴板

## 鸿蒙 7

用 DevEco Studio 打开 `harmony` 目录。如果提示把 SDK 调到鸿蒙 7，按提示升级后运行到手机。工程按 HarmonyOS 5.0.1（API 17）兼容编写，可以装在更新的鸿蒙系统上。

鸿蒙普通应用做不到和安卓一样的整机控制，这是系统权限限制，不是页面没做完：

| 功能 | 安卓 | 鸿蒙 7 普通应用 |
| --- | --- | --- |
| 传文件 | 内部存储 | 应用文件；系统允许时还有下载、文档。也可以点「把选中的文件放进共享」 |
| 投屏 | 整个手机画面 | 只能投桥联自己的页面 |
| 远程控制 | 无障碍控制整个手机 | 只能操作桥联这个页面，不能注入系统触控，也不能代按主页 |
| 剪贴板 | 可以 | 可以 |
| 自动发现 | 可以 | 可以 |

整屏截图和全局触控注入需要系统签名，普通开发者证书拿不到。

## 先用模拟手机试电脑端

不连真机时，可以先看电脑页面是否工作：

```sh
go run ./cmd/fakephone -port 46000 -code 135790
go run ./cmd/qiaolian -no-browser
```

浏览器打开 `http://127.0.0.1:8787`，IP 填 `127.0.0.1`，端口 `46000`，配对码 `135790`。模拟手机的共享目录会打印在终端里。

## 协议

手机监听 TCP `37622`，并用 UDP `37621` 广播。帧格式是大端：`QL`、版本 `1`、消息类型、JSON 长度、二进制长度，然后是 JSON 和二进制数据。电脑、安卓、鸿蒙和 `internal/agent` 使用同一套消息。路径里的 `..` 会被拒绝。连续输错配对码 5 次后，要等 30 秒。
